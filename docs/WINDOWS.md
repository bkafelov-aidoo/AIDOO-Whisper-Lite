# AIDOO Whisper Lite за Windows

Тестова версия 1.0.5 за Windows 10/11, 64-bit Intel/AMD. ARM64 Windows не е проверен. Версията е отделена в клона `codex/whisper-lite-windows`; macOS `main` е запазен.

## Първо стартиране

За регистрация, плащане и създаване на личен ключ следвайте [лесния гайд за OpenAI](OPENAI-API-KEY-GUIDE.md).

1. Стартирайте получения `.exe` инсталатор. Инсталацията е за текущия потребител. Ако WebView2 липсва, инсталаторът го изтегля; необходима е интернет връзка.
2. Отворете AIDOO Whisper Lite. Натиснете „Създай API ключ“, създайте личен ключ в OpenAI Platform и го поставете в приложението. Натиснете „Провери и запази“. Всеки клиент използва свой ключ; инсталаторът не съдържа общ ключ.
3. Изберете микрофон и натиснете „Тествай микрофона“. При липса на достъп отворете „Настройки на микрофона в Windows“ и разрешете достъпа за настолни приложения.
4. Изберете модел, език и дали да запазвате аудио, текст и история. Началният клавиш е F8; можете да го промените от настройките.
5. Поставете курсора в желаното текстово поле, задръжте F8, говорете и отпуснете. Изчакайте транскрипцията. При неуспешно автоматично поставяне използвайте Ctrl+V; текстът остава в клипборда и, ако е включена, в историята.

Затварянето на прозореца оставя приложението до часовника на Windows. От менюто на иконата можете да го отворите отново или да изберете „Изход“.

Ключът се пази в Windows Credential Manager. Частните настройки, история и възстановими записи са в `%LOCALAPPDATA%\AIDOO\Whisper Lite`. Избраните аудио/TXT файлове по подразбиране са в `Documents\AIDOO Whisper Lite\Transcriptions`. Деинсталирането запазва потребителските данни. Ключът се изтрива от настройките на приложението.

Тестовият инсталатор няма Windows цифров подпис. При проверка на Windows издателят може да се показва като непознат. Подписът на macOS версията не подписва Windows приложения.

За подписаните издания и фирмения профил в Azure вижте [гайда за Windows подписване](WINDOWS-SIGNING.md). Използвайте артефакт, обозначен като **signed**, само след успешна проверка на подписите.

## Проверка на физически Windows компютър

Изпълнете преди раздаване на клиенти:

- Инсталиране и първо стартиране на Windows 10/11 x64.
- Личен API ключ: проверка, рестарт с наличен ключ и изтриване на ключа.
- Микрофон: запис, изключен достъп, смяна на устройство и автоматичен fallback.
- Българска и английска клавиатура: F8, задържане/отпускане, нов shortcut и поставяне в Notepad, Word и браузър.
- Двата модела: `gpt-4o-mini-transcribe` и `gpt-transcribe`, реална българска диктовка и сравнение на резултата.
- При прекъснат интернет: запазен запис, ясно съобщение и безопасно възстановяване без автоматично повторно таксуване.
- Икона до часовника, overlay, автоматично стартиране при вход и изход.
- FLAC/TXT, история, локална диагностика и запазване на данните след обновяване/деинсталиране.

Автоматичните тестове използват синтетичен текст и временен тестов запис в Credential Manager. Те не доказват качеството на реалния микрофон или успешна транскрипция с клиентски API ключ. Само потвърждение от потребителя след реалния тест приема тази версия като работеща.

## Разработчик

На Windows с Node.js 22, Python 3.11+, Rust 1.93.1, MSVC C++ Build Tools и Windows SDK:

```powershell
npm ci
npm run check
npm run bundle:windows
```

Инсталаторът е в `src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/`. Workflow `ci-windows.yml` компилира точно състоянието на Windows клона и качва инсталатора, SHA-256, резултатите от проверките и снимка на инсталираното приложение. Той не публикува production release.
