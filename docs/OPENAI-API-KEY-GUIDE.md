# Личен OpenAI API ключ за AIDOO Whisper Lite

Всеки клиент използва свой OpenAI акаунт и плаща собственото потребление. API услугата има отделно плащане от абонамента за ChatGPT. [Информация от OpenAI](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform).

## 1. Влезте в OpenAI

Отворете [OpenAI Platform](https://platform.openai.com/) и влезте в акаунта си. Ако нямате акаунт, създайте го и завършете показаните стъпки за регистрация.

## 2. Заредете кредит за диктовка

Отворете [API Billing](https://platform.openai.com/settings/organization/billing/overview).

1. Натиснете **Add payment details** и въведете данните за плащане.
2. Изберете първоначална сума. Минимумът към 8 октомври 2026 г. е **5 USD**; предварително избраната сума може да е 10 USD.
3. Прегледайте **Use auto-reload**. OpenAI го включва по подразбиране при настройката. Изключете го, ако предпочитате сами да зареждате кредит.
4. Потвърдете плащането и изчакайте няколко минути балансът да се обнови.

Кредитът се използва според потреблението и изтича след една година. Балансът не е моментална граница на разхода: при забавено отчитане може да стане отрицателен. При следващо зареждане използвайте **Buy credits** или **Add to credit balance**. [Актуални условия и помощ за плащането](https://help.openai.com/en/articles/8264644-setting-up-and-managing-prepaid-api-billing).

## 3. Създайте API ключ

Отворете [API keys](https://platform.openai.com/api-keys), натиснете **Create new secret key** и го наречете **AIDOO Whisper Lite**. Копирайте целия показан ключ: OpenAI показва пълния секретен ключ само при създаването му. Пазете го лично и не го изпращайте на други хора. [Помощ за API ключовете](https://help.openai.com/en/articles/4936850-where-do-i-find-my-openai-api-key).

Оставете стандартните права **All** за лесна първоначална настройка. Ако използвате ограничени права, ключът трябва да допуска четене на моделите и създаване на аудио транскрипции; **Read Only** не позволява диктовка. [Видове права на ключовете](https://help.openai.com/en/articles/8867743-assign-api-key-permissions).

## 4. Поставете ключа в приложението

Отворете AIDOO Whisper Lite. Поставете ключа в полето за OpenAI API ключ и натиснете **„Провери и запази“**. На Windows ключът се пази в Windows Credential Manager.

Изберете микрофон, направете теста му и поставете курсора в текстово поле. Задръжте **F8**, кажете кратко изречение и отпуснете клавиша. Изчакайте текстът да се появи.

## Ако не се получи

- **Невалиден ключ:** създайте нов ключ, копирайте го целия и го запазете отново.
- **Липсва кредит:** проверете API Billing и изчакайте балансът да се обнови след плащането.
- **Липсва достъп до модел:** проверете правата и избрания проект на ключа; съобщението в приложението показва причината.
- **Не се чува звук:** разрешете достъпа до микрофона за настолни приложения в настройките на Windows.

Разходите се виждат в [OpenAI Usage](https://platform.openai.com/usage). За работа с Windows приложението използвайте и [краткото ръководство](WINDOWS.md).
