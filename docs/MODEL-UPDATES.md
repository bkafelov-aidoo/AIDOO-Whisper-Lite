# Transcription model recommendations

Source candidate, not an installed release. On main-window initialization, the app checks the public [catalog](https://github.com/bkafelov-aidoo/AIDOO-Whisper-Lite/blob/main/catalog/transcription-models.json) in the background once per native process, when an API key is present. Repeated WebView mounts and concurrent invocations reuse the same completed check. It never opens a window, starts audio, transcribes a sample or changes a model during this check.

The current catalog contains only `gpt-transcribe`, so no upgrade is offered today. Future entries are **curated recommendations**, not automatic guesses based on names or creation timestamps. Before publishing a higher rank, maintainers must review official availability/pricing, compare Bulgarian and English dictation including dental vocabulary, numbers, negation and accidental repetitions, measure latency/cost, and record that evidence in the accompanying review. Rank denotes our reviewed successor preference, not an OpenAI benchmark. Do not publish invented or untested model IDs.

Only models using the existing `gpt-transcribe-v1` protocol (completed FLAC file, JSON text response, `languages[]`, `keywords[]`) can be recommended without an application update. A different protocol requires a new application release. Keep the default entry with ID `gpt-transcribe` and rank 1 in every catalog. Schema version is 1; IDs and ranks must be unique. The app rejects incompatible schemas, oversized responses, invalid IDs/prices/languages and foreign evidence URLs.

If there is a compatible higher-ranked entry supporting the selected language, the native app checks that its ID is listed by OpenAI for the user's key. A key without model-list permission receives no recommendation; dictation continues normally. OpenAI's model list does not establish transcription quality, price or speed. No audio or vocabulary is sent during discovery. GitHub receives no API credential. Each request has an eight-second timeout, HTTPS only and no redirects. Failed/offline checks are quiet; the next application launch may try again.

The bilingual modal appears in the main window only when recording/transcription, onboarding and history deletion are not active. It displays the exact IDs, approximate current/new per-minute prices and the curator's stated benefit. Later/Escape dismisses it for the current UI session. Use model confirms the exact native-held proposal, rechecks the current model and language, and takes the existing exclusive operation guard. A stale proposal, changed API key or active operation cannot change the model. Key replacement/removal invalidates pending recommendations; an already completed check is retried on the next launch.

Consent is an atomic, private `model-choice.json` record. The choice survives restart and takes precedence over ordinary settings saves. Corrupt/invalid choice data falls back to the bundled default. Language, vocabulary, storage, shortcuts and history remain intact; historical entries retain their original model IDs. No model picker is added. The transcript delivery remains one final result after Stop, without preliminary text or Realtime.

Verification covers malformed/duplicate catalogs, incompatible languages/protocols, explicit consent, stale requests, restart persistence, account availability, concurrent-check deduplication, credential isolation and restricted-key/error responses through local HTTP mocks. It does not prove the quality of a future successor or real microphone behavior. No DMG is produced by this source change.
